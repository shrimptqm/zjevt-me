# EMC

- EMC(电磁兼容性) 的全称是（Electro Magnetic Compatibility）， 其定义为“设备和系统在其电磁环境中能正常工作且不对环境中任何事物构成不能承受的电磁骚扰的能力”。 该定义包含两个方面的意思，首先，设备能够抵抗所接受到的干扰而正常工作 (即 EMS)； 其次，设备所发射的电磁干扰不能影响其它设备的正常工作 (即 EMI)。目前在这方面有相应的国际标准和国家标准。针对 EMI 有 GB/T9254-1998（CISPR22B）标准，针对 EMS 有 GB/T17626-1998（IEC61000-4）标准。

	- EMI 干扰：按干扰信号信号可分为共模干扰（COMMON INTERFERE）和差模干扰（DIFFERENTIAL INTERFERE）。凡是来自电源火线（HOT/Live wire）而经由零线（NEUTRAL）返回的杂讯称为差模杂讯。凡是来自电源火线（HOT）或零线（NEUTRAL）而经由地线返回的杂讯，称为共模杂讯。
		- ![[image_1673854215264_0.png]]


	- 电磁干扰主要包括辐射发射和传导发射。
		- 辐射发射：通过空间以电磁波形式传播的电磁干扰。
			- 差模辐射：电流在信号环路中流动产生，PCBA 主要产生差模辐射。
				- ![[image_1643011783630_0.png]] ![[image_1643011972025_0.png]]
			- 共模辐射：由于导体的电位高于参考电位产生，线缆主要产生共模辐射。
				![[image_1643011836636_0.png]]
				 ![[image_1643012035197_0.png]]

		- 传导发射：沿着导体传播的电磁干扰。
			- 共阻抗耦合：由两个回路经公共阻抗耦合而产生，干扰量是电流 i，或变化的电流 di/dt。
			- 容性耦合：在干扰源与干扰对称之间存在着耦合的分布电容而产生，干扰量是变化的电场，即变化的电压 du/dt。
			- 感性耦合：在干扰源与干扰对称之间存在着互感而产生，干扰量是变化的磁场，即变化的电流 di/dt。
- 屏蔽设计的基本原则：
	- 屏蔽体结构简洁，尽可能减少不必要的孔洞，尽可能不要增加额外的缝隙；
	- 避免开细长孔，通风孔尽量采用圆孔并阵列排放。屏蔽和散热有矛盾时尽可能开小孔，多开孔，避免开大孔；
	- 足够重视电缆的处理措施，电缆的处理往往比屏蔽本身还重要；
	- 屏蔽体的电连续性是影响结构件屏蔽效能最主要的因素，相对而言，一般材料本身屏蔽性能以及材料厚度的影响是微不足道的（低频磁场例外）。
