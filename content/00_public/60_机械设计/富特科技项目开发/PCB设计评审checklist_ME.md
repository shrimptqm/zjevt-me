# 一般需求

DXF 是否包含了走线层、钻孔层、焊盘层、丝印层？如果是变更的项目，对比图是否经过确认？改动点是否已经根据改动点清单确认调整完成？

# 过程/制造需求

主要电子器件是否已经按丝印位置装配？且经过公差分析确认装配可行性。器件与器件、器件与壳体之间是否已确认不会存在干涉？（依据功率流走向，兼顾电气绝缘距离、装配干涉、点胶工艺等进行检查）

结构禁布区范围是否已经考虑制造公差、装配公差？结构禁布区内是否已确认没有元器件存在？PE 区是否已确认无非 PE 的表层走线？

定位孔、导向孔、螺钉孔、结构件配合孔的孔径及位置、特殊开槽、MOS 管正反面放置是否经过确认？且经过装配公差分析确认可行。

# 热需求

需要散热的主要功率器件是否与电子确认清楚？器件位置是否合理？是否已确认器件所在位置可做合适的散热特征？且经过公差分析确认散热的可靠性。

所有的 NTC 位置是否与电子经过确认？采样位置是否合理？

从器件散热角度考虑，过孔位置、数量是否合理？热极限器件的过孔数量是否可以增加？结合公差分析，开窗位置、大小是否经过确认？

# 耐候需求

从凝露风险考虑，壳体凸台等冷壁位置周围的非 PE 网络开窗（低压）与壳体尺寸是否大于 2.5mm？

# 电气需求

是否通过隔离带能够清晰确认高压区？PCB 表层铜箔走线与周围部件是否有电气绝缘间隙要求，是否可以通过减小铜箔尺寸避让安规距离？

# 设计标准化

插件 MOS、贴片 MOS、定位孔、导向孔、螺钉孔是否已按标准化进行布局？

平台项目：器件布局是否已经考虑标准化，将尺寸、成本、热设计等做到最优？

# 力学需求

螺钉孔的布局是否考虑过 PCBA 的耐振动性能？主功率器件、插板器件的布局是否考虑耐振动性能？

# 成本优化

PCB 尺寸大小能否缩小？PCB 边界设计是否可以优化拼板布局？
