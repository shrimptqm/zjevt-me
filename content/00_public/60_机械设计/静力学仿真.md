# 静力学仿真

## [[线性静力学分析]] 简介（应用最广）

由经典力学分析可知，物体的动力学通用方程为：

[M]{x"}+[C]{X'}+[K]{x}={F(t)}

式中，[M] 是质量矩阵；[C] 是阻尼矩阵；[K] 是刚度矩阵；{x}是位移矢量；{F(t)}是力矢量；{x'}是速度矢量；{x"}是加速度矢量。

在结构静力学分析中，与时间 t 相关的量都将被忽略，于是上式简化为：[K]{x}={F}

线性分析有两方面的含义：首先是材料为线性，**应力应变关系为线性，变形是可恢复的**。另外，结构发生的是小位移、小应变、小转动，**结构刚度不因变形而变化，即结构刚度矩阵 [K] 是固定**。下图是工程应力应变曲线，当应力低于 σe 时，材料处于弹性阶段，在该段内的σ与ε之间呈线性关系，满足胡克定律：σ=E*ε，E 为材料的弹性模量，比例极限σp 为服从胡克定律的最大值，σe 为保持完全弹性变形的最大应力。

![[image_1641897806654_0.png]]

静力学分析研究的对象应该是处于平衡状态，也就是物体是静止或作匀速直线运动，用于线弹性材料，静态加载的情况。我司常用的静力学仿真场合包括：电气盖板因机器内部气压产生的形变量和应力分析、水道盖板因水道液压产生的形变量和应力分析、MOS 弹片的压力仿真、DC 主变压器弹片的压力仿真等。

### workbench 中静力学分析一般流程

线性静力学分析在 ANSYS Workbench 环境中，对应工具箱（ToolBox）中的 Static Structural(静力学分析) 选项。 Ansys Workbench 线性静力学仿真的一般流程 (以 MOS 弹片为例)：

==启动 Workbench 并建立分析项目：== 双击主界面 Toolbox(工具箱) 中的 Analysis Systems→Static Structural(静力结构分析)。

![[image_1641797465194_0.png]]

==导入创建几何体==（导入 Workbench 之前要进行必要的几何体简化） ：

step1：在 A3(Geometry) 上右击，在弹出的快捷菜单中选择 Import Geometry→Browse 命令，在弹出的“打开”对话框中选择文件路径，导入你要进行分析的 xxx.stp 几何体文件，此时 A3(Geometry) 后？会变为√，表示实体模型已存在；

step2：双击项目 A 中的 A3 Geometry，此时会进入到 Design modeler 界

面，如下图，此界面可以在几何体上进行其他的操作，如画出 MOS 弹片的固定的局部平面等。

![[image_1641795571480_0.png]]

也可以导入到 Space claim 中对模型进行前处理。一定要**检查**模型是否有问题。右击模型 -Check Geometry，无问题即可导入分析。Imprint（压印）指令可检测模型中重合的面，点等特征，可提前修复好以免画网格时出现错误。

![[image_1690274584300_0.png]]![[image_1690274818382_0.png]]![[image_1690275071915_0.png]]

==材料参数设置==（材料设置的必要参数是泊松比、弹性模量、密度，特殊参数是 [[00_public/60_机械设计/屈服强度]]，用于安全系数的判定） :

Step1：双击项目 A 中的 A2(Engineering Data) 选项，进入材料参数设置界面，在弹出的快捷菜单中选择 Engineering Data sources(工程数据源) 命令。

Step2：在 Engineering Data Sources 表中选择 A13 栏 EVTECH-1 选项，然后单击 Outline of General Materials 表中的 A12 栏 SUS301 后的 +（添加）按钮。

Step3：在界面的空白处右击，在弹出的快捷菜单中选择 Engineering Data Sources（工程数据源）命令，返回初始页面中。根据实际工程材料的特性，在 Properties of outline Row 7:SUS301 表中可以修改材料的特性。

![[image_1641801421995_0.png]]

![[image_1641801253658_0.png]]

==接触设置：== 接触类型有以下 5 类，本例中 MOS 弹片和 MOS 之间设置为带摩擦的接触，摩擦系数 0.1（摩擦系数越大越难收敛）。 复杂模型体需检查各个面之间的接触有没有问题，防止有些面挨的近，ansys 默认其接触。

**Bonded（接合）**：在接触面和接触边之间不存在切向的相对滑动或者法向的相对分离，如焊接。

**No Separation（无分离）**：不允许发生法向相对分离，可以发生切向无摩擦滑动。

**Frictionless（无摩擦）**：无摩擦单边接触，摩擦系数为 0，允许分离，出现分离，法向力就为 0。

**Rough（粗糙）**：与 Frictionless 类似，两物体之间有静摩擦力，不发生相对滑动，摩擦系数无限大。

**Frictional（摩擦）**：最接近实际的情况，可以法向分离，切向可以滑动，需要设置摩擦系数。

==网格划分：== 选择 Mechanical 界面左侧 Outline(分析树) 中的 Mesh 选项，此时可以在 Details of "Mesh"(参数列表) 中修改网格参数，本例中将 MOS 弹片的网格大小设置为 2mm，其余采用默认设置，设置完成后在 Outline（分析树）中的 Mesh 选项右击，在弹出的快捷菜单中选择 Generate Mesh 命令，完成网格划分。

==施加约束 (与载荷) :==

**添加固定约束：选择 Mechnical 界面左侧的 Outline（分析树）中的 Static Structural(A5) 选项，然后选择 Environment 工具栏中的 Supports（约束）→Fixed Support(固定约束) 命令，此时在分析树中会出现 Fixed Support 选项，选择 Fixed Support 选项，选择需要施加固定约束的面。本例中需给 MOS 弹片施加两个面的固定约束，如下图。

![[image_1641872921917_0.png]]![[image_1641887740192_0.png]]

施加位移约束**：如上述添加约束，选择 Environment 工具栏中的 Supports（约束）→Displacement(固定约束) 命令，此时在分析树中会出现 Displacement 选项，选择 Displacement 选项，选择需要施加固定约束的面和需要施加的位移量，本实例在 Y 方向施加 1mm 的位移。

![[image_1641887251685_0.png]]

==仿真结果及后处理:==

**求解仿真结果：在 Outline(分析树) 中的 Static Structural(A5) 选项上右击，在弹出的快捷菜单中选择 Solve 命令，此时会弹出进度显示条，表示正在求解，当求解完成后进度条自动消失。

结果后处理**：求解完成后，是看不见任何结果信息的，要进行结果后处理。选择 Outline（分析树）中的 Solution（A6）选项，右击 Solution 选项插入你想显示的仿真结果命令。本实例中插入 Stress（应力）→Equivalent (von-Mises）命令、Strain（应变）→Equivalent Stress(等效应力）命令、Deformation（变形）→Directional(各方向变形）命令，此时会在分析树中出现你想获得的仿真结果选项，在 Outline（分析树）中的 Solution（A6）选项上右击，在弹出的快捷菜单中选择 Evaluate All Results 命令，求解完成后就可以可以查看仿真结果。

[[非线性静力分析]] 简介

非线性静态分析中，刚度 [K] 依赖于位移{x}，不再是常量，即 [K(x)]{x}={F(t)}.

非线性行为，简单来说就是，**如果载荷能够引起结构刚度的显著变化，此结构就是非线性的，即结构刚度矩阵 [K] 是变化的**。结构刚度改变的典型原因有如下几点：

1、**材料非线性**：应变超出弹性极限，即产生塑性变形。

2、**几何非线性**：大挠度，如钓鱼过程中的鱼竿受力变形，其变化的几何外形会导致非线性行为。结构发生大挠度现象时，网格单元的方向可能发生变化，导致结构刚度矩阵发生改变，如悬臂梁端部承受竖直向下的载荷时，悬臂梁向下弯曲，当悬臂梁向下弯曲很小时，可以认为网格单元不发生变化，而对问题做线性处理，但如果弯曲很大，网格单元的方向将发生明显改变。**结构刚度由单元刚度和方向决定**。

3、**接触状态**：如两个物体之间的接触变形、接触状态（接触 - 分离）的改变，此时会发生刚度的突然变化。

非线性静力学分析在 ANSYS Workbench 环境中进行分析时，需要注意的事项包括：

1、**打开大变形选项：设置分析选项时，将大变形选项打开。

2、**添加材料数据：添加材料数据时，应定义弹性材料特征，如杨氏模量、泊松比等，然后给出非线性材料特性。

3、**简化模型：非线性分析需要使用很多次迭代才能最终求出结果，每次迭代的时间与网格的数量成正相关关系，为了节省求解时间，在进行非线性分析时，尽可能简化最终模型。

4、**网格简化：网格划分首先应提供足够用于分析应力的网格密度，在求解大型分析时前，应该检查网格形状，已确定网格质量满足要求，因为在大应变分析的每一个子步中，第一次迭代后，网格变得严重扭曲，可能产生的不良形状网格单元影响求解的精度，甚至求解失败。修改原始网格是防止出现不良形状的一种办法，例如在拉伸实验中试件在颈缩部位会出现严重扭曲，网格也会出现严重扭曲，一种解决方法是在颈缩部位细化网格，使网格扭曲程度下降，另一种方法就是你使用三角单元代替四边形单元，防止网格中出现大的内角。

非线性静力学分析在 ANSYS Workbench 环境中对应工具箱（ToolBox）中的 Static Structural(静力学分析) 选项。我司密封圈设计分析就使用了非线性静力学仿真分析 ,下面 PPT 中介绍了密封圈非线性分析仿真过程。
