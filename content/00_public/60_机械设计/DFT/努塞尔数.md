# 定义

*Nu*努塞尔数是一个无量纲数，用来描述流体内的**热对流强度**和**热传导强度**的比值。

$$ N u_{L}=\frac{\text { convective heat transfer (热对流强度) }}{\text { conductive heat transfer (热传导强度) }}=\frac{h L}{\kappa} $$

![[Pasted image 20240619112830.png]]

对于**热传导**可以用**傅里叶导热定律**计算热通量（heat flux）：

![[Pasted image 20240619112842.png]]

对于**热对流**可以用**牛顿冷却定律**计算热通量（heat flux）：

![[Pasted image 20240619112854.png]]

因此：

![[Pasted image 20240619112907.png]]

 Nu=1 表示流体内部只发生热传导。

 Nu 努塞尔数越大，表示热对流效率越高。

 对于湍流而言，Nu 努塞尔数通常为 100~1000 之间，其通常为 Re[[雷诺数]] 和 Pr 普朗特数的函数。

![[Pasted image 20240619113113.png]]

需要注意的是：

特征长度的选择应在边界层的生长方向（或厚度）上；特征长度的一些示例是：（外部）横流（垂直于气缸轴线）的气缸的外径，经受自然对流的垂直板的长度或球体的直径。 对于复杂的形状，长度可以定义为流体的体积除以表面积。

流体的热导率通常（但不总是）评判膜温度，这对于工程目的可以计算为散装流体温度和壁表面温度的平均值。

与上面给出的定义相反，称为平均努赛尔数。通过将长度作为距离表面边界到当地感兴趣点的距离来定义局部努塞尔数。
