# 公差

定义：

1、公差是实际参数值的允许变动量。参数，即包括机械加工中的几何参数，也包括物理、化学、电学等学科的参数。

2、对于机械制造来说，制定公差就是为了确定产品的几何参数，使其变动量在一定范围之内，以便达到互换或配合的要求。

3、而在数学中，公差是对于等差数列这一类特殊数列而言的，它是指在等差数列中后一项与前一项的差（即第 n 项与第 n-1 项的差）。

公差分类：

1、尺寸公差。指允许尺寸的变动量，等于最大极限尺寸与最小极限尺寸代数差的绝对值。

2、形状公差。指单一实际要素的形状所允许的变动全量，包括直线度、平面度、圆度、圆柱度、线轮廓度和面轮廓度 6 个项目。

3、位置公差。指关联实际要素的位置对基准所允许的变动全量，它限制零件的两个或两个以上的点、线、面之间的相互位置关系，包括平行度、垂直度、倾斜度、同轴度、对称度、位置度、圆跳动和全跳动 8 个项目。

# **公差分析的概念**

公差分析是指在满足产品功能、性能、外观和可装配性等要求的前提下,合理定义和分配零件和产品的公差,优化产品设计,以最小的成本和最高的质量制造产品。

# **公差分析的目的**

公差分析作为面向制造和装配的产品设计中非常有用的工具,可以帮助研发工程师实现以下目的：

+ 合理设定零件和产品的公差以降低产品制造和装配成本
+ 判断零件的可装配性,判断零件是否会在装配过程中发生干涉

以 EC24 公差分析为例，判断 EC24 ACIN EMI 板排针排母的塑胶座是否干涉，以及信号接插件塑胶座与 MB 板是否干涉；

+ 判断零件装配后产品关键尺寸是否满足外观、质量以及功能等要求
+ 优化产品的设计

当通过公差分析发现产品设计不满足要求时,一般有两种方法来解决问题。其一是通过严格的零件公差来达到要求,但这会增加零件的制造成本; 其二是通过优化产品的设计 (例如增加装配定位特征) 来满足产品设计要求,这是最好的方法,也是公差分析的意义所在。

+ 分析和寻找制造和装配过程中出现问题的根本原因

公差分析除了用于产品设计中,还可用于产品装配完成后,当产品的装配尺寸不符合要求时,可以通过公差分析来分析制造和装配过程中出现的问题,寻找问题的根本原因。

# **公差分析的总流程**

## 流程

1. 定义公差分析的目标尺寸和判断标准
2. 建立闭合尺寸链
3. 将非对称公差转成对称公差
4. 判断尺寸链中尺寸的正负
5. 计算目标尺寸的名义值
6. 选用公差分析的方法
7. 公差分析的计算
8. 公差分析结果图纸标注

## 要点讲解

**1、定义公差分析的目标尺寸和判断标准**

以 EC24 和 E28A 的公差分析为例，大部分时间不是花在做公差分析的计算上，因为有公差分析表格辅助计算，反而是定义公差分析的目标尺寸和判断标准更花时间

**2、建立闭合尺寸链**

尺寸链，是指在产品的装配关系中，由互相联系的尺寸按一定顺序首尾相接排列而成的封闭尺寸组；

尺寸链两大特点：一是^^封闭性^^，尺寸链是由多个尺寸首尾相连；二是^^关联性^^，组成尺寸链的每个尺寸都与目标尺寸有关联性，尺寸链中每个尺寸的精度会影响到目标尺寸的精度； ![[image_1642588980858_0.png]]

**3、将非对称公差转成对称公差**
![[image_1642589060438_0.png]]
**4、判断尺寸链中尺寸的正负**

可用等式法来判断尺寸链的正负，如上图所示：

D=A+B+C+X，所以目标尺寸 X=D-C-B-A，正负立定，同样的符号尺寸链箭头相同。

**5、计算目标尺寸的名义值**

如果公差分析计算出的目标尺寸名义值与设计值不相等，则说明尺寸定义错误。公差标注为对称公差的好处：计算出的目标尺寸名义值与 3D 数模测量值相等

**6、选用公差分析的方法**

公差分析法通常分为极值法和统计分析法，前者通常用于尺寸链≤3 个时，后者通常用于尺寸链 4 个以上，后面会详细讲解

**7、公差分析的计算**

**8、判断和优化**

当公差分析的结果不满足要求时，推荐做法：

a）调整尺寸链中的尺寸大小

以 EC24 为例，ACIN EMI 板的合高 7mm 的排针排母，供应商现有的排针排母规格书进行公差分析，发现排针排母的塑胶座会有较大概率干涉，后面将排针塑胶座高度由 2.54mm 降低至 2.0mm，此时排针排母塑胶座间隙>0，满足要求；

![[image_1642591274266_0.png]]

b）减少尺寸链的长度

减少尺寸链的长度的方法有两种：减少尺寸链中的零件数量；同一零件中，减少尺寸链的长度，避免公差累积；

以 A9E 微动开关为例，以往项目如 ME+ 项目，微动开关是安装在壳体上，尺寸链跨越机壳、电气盖板、PDU 盖板和 2 根 CIPG，总共 5 个零件；而 A9E 项目直接将微动开关安装在电气盖板上，尺寸链跨越电气盖板、PDU 盖板和 1 根 CIPG，通过减少尺寸链中的零件数量来减少了尺寸链长度，从而极大提高微动开关可靠性

![[image_1642592267903_0.png]]

当公差分析的结果不满足要求时，不推荐做法：

c）减少尺寸链中的尺寸公差大小

减少尺寸链的公差大小是产品设计中最常用的方法。当然,这一定不是最好的方法，零件的尺寸公差不是想怎么调整就可以怎么调整的,尺寸公差取决于零件的制造工艺所能提供的^^制造精度^^，如果尺寸公差越严格,但是零件的制造工艺达到这样的精度就会花费越高的成本,甚至无论如何都达不到这样的精度,那么整个公差分析就毫无意义；

当然,，调整零件尺寸公差并且征得供应商认可的情况下,可以要求严格的零件公差。

# **公差分析方法**

## **极值法**

### 极值法定义

定义极值法（WC，Worse Case）：极值法是考虑零件尺寸最不利的情况，通过尺寸链中尺寸的最大值或最小值来计算关键尺寸的值；

计算公式： ![[image_1642596044670_0.png]]

### 极值法计算实例

题目：A 尺寸 54.00±0.20，B 为 12.00±0.10，C 为 13.00±0.10，D 为 16.00±0.15，E 为 12.50±0.10，利用极值法求关键尺寸 X 的名义值和公差。

![[image_1642640934466_0.png]]

计算过程：

1. 计算 X 的名义值：DX= DA+ DB+ DC+ DD+ DE = 54.00 +(-12.00) + (-13.00) + (-16.00) + (-12.50)= 54.00 -12.00 -13.00 -16.00 -12.50= 0.50mm
2. 计算 X 的公差：TX= TA+ TB+ TC+ TD + TE = 0.20 + 0.10 + 0.10 + 0.15 + 0.10 = 0.65 mm
3. X=0.5±0.65mm
